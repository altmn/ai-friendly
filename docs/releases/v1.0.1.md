# AI-friendly 1.0.1

The main page now starts with what AI-friendly helps you do, followed by an
illustrative furniture-shop finding and concise prompts for audits, setup,
troubleshooting, and maintenance. Copyable examples include the needed input.

This release preserves audit instructions, CLI behavior, rule and schema
contracts, evidence boundaries, and privacy requirements. Distribution versions
advance to 1.0.1; unchanged protocol and catalog versions remain 1.0.0.

Download the canonical package for the complete portable `ai-friendly-audit/`
directory. The development archive contains the verification tooling and
synthetic fixtures. Both archives exclude installed dependencies. See
[installation](https://github.com/altmn/ai-friendly/blob/v1.0.1/docs/getting-started.md)
and verify downloads against `SHA256SUMS`.

Native support remains provisional: prior scoped Codex and browser trials do not
establish broad host compatibility, full-audit reliability, or backend effects.
There is no published ChatGPT plugin route in this repository. See the README
and linked acceptance records for the existing evidence and limitations.
