## Changes

Focused read-only supplied-source requests now take a scoped workflow instead
of loading live-browser procedures, the entire catalog and its generated
duplicate. Broader collection and complete canonical bundles retain their full
workflow, guide coverage and evidence gates. Safety, privacy, action scope and
unknown effects remain invariant. Neither reasoning nor the timeout was relaxed.

The entrypoint, source workflow, canonical AFF-SEM-002 procedure and report
template require both non-sensitive field-name strings together. Absence,
ambiguity and privacy omissions remain explicit. Source labels, declared ARIA
attributes/referenced text and computed browser names stay distinct.

Two optional read-only CLI views support the workflow:

- `rules --ids AFF-SEM-002,AFF-FORM-004` returns full selected records, including
  limitations, false positives and linked owners. It is a partial selection,
  not a complete catalog.
- `inspect-source --input FILE` parses inert UTF-8 HTML and returns source labels,
  declared ARIA names and referenced-label text. It excludes entered values,
  selected option text and textarea contents. It computes no browser names,
  executes no page scripts, makes no network requests and writes no files.
  Input defaults to 262144 bytes; returned output is capped at 65536 bytes,
  50 controls and 1024 characters per retained name. Omissions/errors remain
  explicit; pattern minimization still requires review before sharing.

The native harness now applies absolute RPC/turn deadlines, including turn
startup. Notifications cannot continually reset the wait. Timeout paths close
the owned server without waiting another RPC window for interruption. Compaction
requires its own completed context item and matching turn, rejecting stale
same-thread completions. Execution and bounded cleanup are separate budgets.
These changes do not turn incomplete historical runs into passes.
