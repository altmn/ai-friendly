# Security policy

Report repository-code vulnerabilities privately through the repository host's
private [vulnerability-reporting feature](https://github.com/altmn/ai-friendly/security/advisories/new).
If unavailable, ask the
maintainer for a confidential channel without posting exploit details publicly.
No private channel, response deadline, or ongoing support commitment is promised.

Include affected version/file, impact, and a minimal synthetic reproduction.
Never include real secrets, browser profiles, account captures, or bulk logs.
Network-scope escapes, unsafe writes, and unintended disclosure are in scope.
General model quality belongs in ordinary synthetic issue reports. The current
source candidate is the maintained development target; no released version has
an asserted support lifetime.
